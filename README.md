# Enmanuel Reynoso Salazar

Software engineer in the Dominican Republic. I build and run software in production, and I care about
knowing exactly where it breaks.

I am the founder and lead developer of [AsistoYA](https://asistoya.com), a multi-tenant school attendance
SaaS: React and TypeScript on web, iOS and Android, Node.js functions, Hikvision facial terminals over
ISAPI, and a self-hosted Appwrite stack on an Oracle Cloud ARM server.
